    Exportar para o gabinete

    O pacote traz CSV (Excel, separador ;), GeoJSON, KML, KMZ com fotos, DXF em PT-TM06 e todas as fotos.

    Projetos

    Toca num projeto para o tornar ativo. Os registos novos ficam no projeto ativo; o mapa, a lista e as exportações mostram só esse projeto.

    Técnico

    Base de códigos postais (CTT)

    Carrega o CTT_CP.txt (o mesmo do VALIDA). Nas moradas, a app sugere a rua e preenche o código postal e a localidade pelo nº de polícia. Fica guardada no dispositivo e funciona sem rede.

    Ainda não carregada.

    Mapa Google

    Cola aqui a tua chave da Google Maps Platform (com a Map Tiles API ativa). Fica guardada só neste dispositivo.

    Trabalhar sem rede

    A aplicação abre e grava registos sem rede. O mapa sem rede só mostra as zonas já vistas ou guardadas: antes de sair, abre a zona de trabalho no mapa e toca em "Guardar zona".
